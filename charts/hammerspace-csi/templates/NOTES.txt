If it doesn't exist yet, create it now:

    --namespace {{ include "hammerspace-csi.namespace" . }} \
    --from-literal=username='<PLACEHOLDER>' \
    --from-literal=password='<PLACEHOLDER>' \
    --from-literal=endpoint='https://<anvil>'

Until it exists, the controller and node pods will fail to start
(CreateContainerConfigError — the driver's env references this Secret's keys).

IMMUTABILITY WARNING
  CSIDriver.spec.attachRequired and CSIDriver.spec.fsGroupPolicy are IMMUTABLE
  once the CSIDriver/com.hammerspace.csi object exists. Changing
  csiDriver.attachRequired or csiDriver.fsGroupPolicy and running
  `helm upgrade` will FAIL (the API server rejects the patch) — delete the
  object first, then re-apply:

    kubectl delete csidriver com.hammerspace.csi
    helm upgrade {{ .Release.Name }} <chart> --namespace {{ include "hammerspace-csi.namespace" . }} --reuse-values

  Deleting the CSIDriver object briefly stops kubelet from routing new mount
  requests to the driver; already-mounted volumes are unaffected.

  The controller StatefulSet's and node DaemonSet's spec.selector.matchLabels
  are immutable too, but this chart does not expose them as values.
